\section{The operation we are proving correct}
In multiple instance learning (MIL), a bag contains feature vectors for a
variable number of instances. A batch often stores those vectors in a larger
array with unused rows. Attention pooling should depend on the real instances,
regardless of how much padding was added or how the instances were ordered.

Let $I$ be a finite set of row indices, $d$ the number of features, and
\[
 x_i\in\mathbb R^d,\qquad s_i\in\mathbb R,\qquad m_i\in\{0,1\}.
\]
Here $x_i$ is an instance's feature vector, $s_i$ its attention logit, and $m_i$
its validity mask. For a prefix of length $\ell$ stored in $n$ rows,
$m_i=1$ exactly when $0\leq i<\ell$. The proofs allow any mask, including
invalid rows between valid ones.

Define the attention mass and the safely masked features by
\[
 w_i=\begin{cases}e^{s_i},&m_i=1,\\0,&m_i=0,\end{cases}
 \qquad
 v_i=\begin{cases}x_i,&m_i=1,\\0,&m_i=0.\end{cases}
\]
The normalizer and the pooled vector are
\begin{equation}\label{eq:pool}
 Z=\sum_{i\in I}w_i,\qquad
 D(Z)=\begin{cases}Z,&Z>0,\\1,&Z\leq0,\end{cases}
 \qquad
 \result{\Pool(x,s,m)=\frac{\sum_{i\in I}w_i v_i}{D(Z)}}.
\end{equation}
All sums and vector operations are componentwise. If at least one row is valid,
$e^{s_i}>0$ gives $Z>0$, and the valid weights $w_i/Z$ sum to one. If every row
is invalid, both sums vanish and the output is the zero vector. This also
covers a bag with no rows.

\subsection*{Why masking features alone is insufficient}
Take two scalar instances $x_1=2$, $x_2=6$, both with logit zero. The correct
output is $(2+6)/2=4$. If we add a zero-feature padded row but leave it inside
softmax, its mass is $e^0=1$, giving $(2+6+0)/3=8/3$ instead.
The padded row must contribute zero to \emph{both} the numerator and normalizer.

\section{The two invariance proofs}
\subsection*{(a) Adding padding leaves the output unchanged}
Let $P$ be any finite set of added rows, disjoint from $I$. Give those rows
arbitrary real feature vectors and logits, but set their masks to zero.
Write the extended arrays as $x',s',m'$. On original rows they equal $x,s,m$;
on rows in $P$, $m'_p=0$, so $w'_p=0$ and $v'_p=0$.

Splitting the sum over the disjoint union gives
\begin{align*}
 Z'&=\sum_{r\in I\sqcup P}w'_r
     =\sum_{i\in I}w_i+\sum_{p\in P}0=Z,\\
 N'&=\sum_{r\in I\sqcup P}w'_r v'_r
     =\sum_{i\in I}w_i v_i+\sum_{p\in P}0
     =\sum_{i\in I}w_i v_i=N.
\end{align*}
Since the normalizer is unchanged, its guarded denominator is unchanged too:
\[
 \result{\Pool(x',s',m')=\frac{N'}{D(Z')}=
 \frac{N}{D(Z)}=\Pool(x,s,m).}
\]
The argument does not require a nonempty bag. It also does not require the
padded features or logits to be zero; only their masks must be zero.

\subsection*{(b) Permuting paired rows leaves the output unchanged}
Let $\pi:I\to I$ be a bijection. Move each instance together with its logit
and mask:
\[
 x'_i=x_{\pi(i)},\qquad s'_i=s_{\pi(i)},\qquad m'_i=m_{\pi(i)}.
\]
Then $w'_i=w_{\pi(i)}$ and $v'_i=v_{\pi(i)}$. A bijection visits every
original row exactly once, so reindexing each finite sum gives
\begin{align*}
 Z'&=\sum_{i\in I}w_{\pi(i)}=\sum_{r\in I}w_r=Z,\\
 N'&=\sum_{i\in I}w_{\pi(i)}v_{\pi(i)}
     =\sum_{r\in I}w_r v_r=N.
\end{align*}
Consequently,
\[
 \result{\Pool(x\circ\pi,s\circ\pi,m\circ\pi)=\Pool(x,s,m).}
\]
A permutation of only the real instances is a special case: extend it to the
whole array by fixing the padded positions. A more general permutation can
move padded positions too, provided the mask moves with them.

\subsection*{When logits are computed from the instances}
A shared instance-local scorer $f:\mathbb R^d\to\mathbb R$ satisfies
$s_i=f(x_i)$. After shuffling, $f(x'_i)=f(x_{\pi(i)})=s_{\pi(i)}$, exactly
as required above. This includes a shared linear layer, MLP, or gated scorer.
A scorer that depends on position or an order-dependent encoder requires
an additional argument.

\section{How Lean expresses the proof}
The general proofs are in \code{MaskedAttention/Basic.lean}. They quantify
over arbitrary finite row sets and feature dimensions, rather than testing
particular feature values.

\subsection*{Permutation: the same reindexing identity twice}
The theorem \code{pool_reindex} uses the identity
\[
 \sum_{k\in K}g(e(k))=\sum_{i\in I}g(i).
\]
It first applies this identity to $g(i)=w_i$ and then to
$g(i)=w_i v_{i,j}$. Once both sums are rewritten, the two sides of the pooling
equality are identical. The theorem permits different finite index types
$K$ and $I$ as long as they are related by a bijection.

\subsection*{Padding: split the index set and simplify the zero terms}
Lean represents the padded row set by a disjoint union, \texttt{Sum I P}.
\code{Sum.elim} selects the original data on one side and padded data on the
other. The padding mask is always false. The actual checked proof body is
\begin{lstlisting}
funext j
simp [pool, mass, Fintype.sum_sum_type]
rfl
\end{lstlisting}
Here \code{Fintype.sum_sum_type} splits the union sum into two sums.
\code{simp} unfolds the definitions and removes zero terms; \code{rfl}
finishes the remaining definitional equality. The short script is backed
by general finite-sum results from mathlib.

\subsection*{Additional checked properties}
\code{pool_masked_congr} proves that changing invalid features or logits has
no effect. \code{pool_all_masked} proves the zero-output convention.
\code{attention_permutation} applies the permutation theorem to an arbitrary
shared instance-local scorer. These results use the same pooling definition
as Equation~\eqref{eq:pool}.

\section{From the JAX function to the certified theorem}
The certified JAX kernel in \code{python/pooling.py} is
\begin{lstlisting}[language=Python]
def masked_pool(values, logits, mask):
    safe_logits = jnp.where(mask, logits, 0.0)
    safe_values = jnp.where(mask[:, None], values, 0.0)
    weights = jnp.where(mask, jnp.exp(safe_logits), 0.0)
    total = jnp.sum(weights)
    denominator = jnp.where(total > 0.0, total, 1.0)
    return jnp.sum(weights[:, None] * safe_values,
                   axis=0) / denominator
\end{lstlisting}
\code{values} has shape $[n,d]$, while \code{logits} and \code{mask} have
shape $[n]$. Safe selection suppresses invalid values before exponentiation
and multiplication; an invalid logit is not allowed to create attention mass.

\subsection*{The connection is checked at each function boundary}
\begin{enumerate}
\item JAX traces the kernel for the fixed shapes $[3,2]$ and $[5,2]$.
\item Sasha Rush's \code{jax-lean} library emits a readable Lean tensor function
and a separately imported, typed mathematical Jaxpr for each shape.
\item Generated translation certificates prove that evaluating each imported
Jaxpr agrees with its readable Lean function for every modeled real input.
\item \code{generated3_spec} and \code{generated5_spec} identify those
functions with the general pooling definition. They check the mask branches,
reductions, and guarded denominator.
\item The generic invariance theorems apply. The final statements
\code{certified_permutation} and \code{certified_padding}
carry these properties to the mathematical Jaxpr evaluator.
\end{enumerate}
The concrete padding theorem compares the separately traced 3-row and 5-row
kernels with two arbitrary added rows whose masks are false. The reusable
padding theorem covers any finite number of added rows. Generated Jaxprs
have fixed shapes; the general theorem does not make JAX shape-polymorphic.

\subsection*{What the certificate establishes}
The proof is an exact identity in \textbf{ideal real arithmetic}. It does
not certify floating-point rounding, XLA execution, or the correctness of
JAX itself. JAX tracing and the Python importer remain trusted.

The runtime helper \code{stable_masked_pool} subtracts the maximum valid
logit before exponentiation, avoiding overflow for large finite logits.
That helper and the prefix-length/scorer wrapper \code{attention_pool}
are numerically tested, but their own Jaxprs are not certified in this version.
The real-valued theorem excludes NaN and infinity; runtime tests separately
check that nonfinite values in invalid rows are suppressed.
